## Aprender construyendo sistemas reales

CoDrone EDU EIT conecta fundamentos de programación con problemas de sensores,
señales, comunicaciones, datos, inteligencia artificial y trabajo en equipo. El
portal está pensado para estudiantes, docentes y ayudantes universitarios.

<CardGrid>
  <Card title="Programación con propósito" icon="seti:java">
    Java y Python aplicados a misiones observables, seguras y evaluables.
  </Card>
  <Card title="Datos del mundo físico" icon="chart">
    Telemetría, incertidumbre, filtrado, visualización y modelos reproducibles.
  </Card>
  <Card title="Sistemas conectados" icon="setting">
    Puertos seriales, concurrencia, redes, seguridad y coordinación distribuida.

## Estado del proyecto

Este es el primer portal del fork universitario. La biblioteca Java heredada se
mantiene separada del contenido docente y su referencia se genera desde el código.
La integración Python usa como referencia primaria el paquete oficial
`codrone-edu` y la documentación de Robolink.

:::caution[Hardware real]
Ninguna actividad de vuelo se considera validada hasta probarla con el modelo,
firmware, batería y entorno indicados. Comienza siempre por
[seguridad](/JCoDroneEdu/inicio/seguridad/).
:::
