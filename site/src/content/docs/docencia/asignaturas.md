La prioridad **A** indica que el dron es central; **B**, que funciona como
laboratorio complementario; y **C**, que se usa como caso de estudio o proyecto.

| Trayecto | Prioridad A | Prioridad B/C |
| --- | --- | --- |
| Programación y algoritmos | Programación, Programación avanzada, Estructuras de datos y algoritmos, Grafos y algoritmos | Arquitectura y organización de computadores |
| Software y sistemas | Sistemas operativos, Sistemas distribuidos, Ingeniería de software, Arquitectura de software | Arquitecturas emergentes |
| Datos e IA | Inteligencia artificial, Data science, Reconocimiento de patrones, Probabilidades y estadísticas | Bases de datos, Bases de datos avanzadas, Deep learning, Big data |
| Señales y electrónica | Electrónica y electrotecnia, Señales y sistemas, Procesamiento digital de señales | Comunicación por luz visible |
| Redes y comunicaciones | Comunicaciones digitales, Tecnologías inalámbricas, Taller de redes y servicios, Algoritmos de ruteo, Criptografía y seguridad | Redes de datos, Redes móviles, Redes ópticas |
| Producto y gestión | Proyecto TIC I, Proyecto TIC II, Procesos ágiles | Evaluación de proyectos, Gestión organizacional, Gestión en innovación |
| Experiencia de usuario | Desarrollo web y móvil | Tableros y aplicaciones de apoyo para los demás trayectos |

## Primer ciclo recomendado

1. **Programación:** secuencias, decisiones y bucles para una ruta segura.
2. **Estructuras y grafos:** cola de comandos y ruta de menor costo.
3. **Probabilidades:** repetibilidad e incertidumbre de sensores.
4. **Sistemas operativos:** puerto serial, concurrencia y temporización.
5. **Desarrollo web/móvil:** tablero de telemetría.

El mapa detallado y los primeros proyectos por cada una de las 37 asignaturas se
mantienen en el [acta del proyecto](https://github.com/Ericktz/JCoDroneEdu/blob/main/docs/CODRONEDU_EIT_PROJECT_CHARTER.md).
